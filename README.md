## 🚀 Como clonar o projeto

Abra seu terminal e digite os seguintes comandos:

```bash
git clone https://github.com/seu-usuario/landingpage-cafeteria.git
cd landingpage-cafeteria
```

Ou faça o download como `.zip` e extraia em seu servidor local (ex: XAMPP ou WAMP).

---

## 🗂️ Estrutura de pastas

```
landingpage/
│
├── index.php              ← Página principal da landing page
├── processa.php           ← Arquivo que trata os dados do formulário
├── css/
│   └── estilo.css         ← Estilo personalizado da página
├── imagens/
│   └── cafe.jpg           ← Imagem da landing (pode alterar)
└── README.md              ← Este arquivo
```

---

## ⚙️ Como executar

1. Instale um servidor local, como o [XAMPP](https://www.apachefriends.org/pt_br/index.html).
2. Coloque a pasta `landingpage/` dentro do diretório `htdocs/`.
3. Inicie o Apache pelo painel do XAMPP.
4. Acesse no navegador:

```
http://localhost/landingpage/
```

---

## ✏️ Como personalizar

Você pode adaptar essa landing para qualquer tipo de comércio local:

| Elemento         | Como modificar?                                  |
|------------------|--------------------------------------------------|
| Título e descrição  | Editar o conteúdo dentro do `<header>` em `index.php` |
| Imagens          | Substituir o arquivo em `imagens/`               |
| Formulário       | Adicionar mais campos em `index.php` e `processa.php` |
| Cores e fontes   | Modificar em `css/estilo.css`                    |
| Nome do projeto  | Renomeie o diretório e os textos                 |
